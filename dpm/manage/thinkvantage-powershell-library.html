3.1.1

3.1.1One library, native scripting control

The ThinkVantage PowerShell Library gives IT admins native scripting control over Lenovo commercial PC management. Everything installs from the PowerShell Gallery with Install-Module or Install-Script, and updates with Update-Module.

SolutionWhat it doesInstall
Lenovo.Client.UpdateDriver, BIOS and firmware update discovery, download and installation, with signature verification and WMI history.Install-Module Lenovo.Client.Update
Lenovo.Client.ScriptingUtility cmdlets for warranty, BIOS, CVE lookup, driver and HSA pack search, update history and log analysis.Install-Module Lenovo.Client.Scripting
Lenovo.BIOS.ConfigReads and modifies BIOS settings through WMI. Backs Think BIOS Config Tool V2.Install-Module Lenovo.BIOS.Config
Lenovo.Bios.CertificatesCertificate-based BIOS authentication: passwordless BIOS management signed with a local key file or key served from an Azure Key Vault.Install-Module Lenovo.Bios.Certificates
3.1.2

3.1.2Script and module solutions

These pair a standalone script, graphical or automation-oriented, with a module whose cmdlets you can also call directly from your own scripts.

  • Think BIOS Config Tool with Lenovo.BIOS.Config. A WPF GUI for viewing, changing, exporting and deploying BIOS settings. The module's Export-LnvWmiSettings and Import-LnvWmiSettings cmdlets do the same work without the GUI.
  • Lenovo BIOS Certificate Tool with Lenovo.Bios.Certificates. Replaces Supervisor Password authentication with X.509 certificate signing. The private key never leaves its secure store, which suits zero-trust and cloud-managed fleets.
  • ThinkVantage Repository Manager. A script-based, modern alternative to Update Retriever for building and maintaining local update repositories, backed by the Lenovo.Client.RepositoryManager module. Repositories it builds work with both Lenovo.Client.Update and Commercial Vantage.
Install-Script ThinkBiosConfigUI
Install-Script LnvBiosCertInterface
Install-Script ThinkVantageRepositoryManager

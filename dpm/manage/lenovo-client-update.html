Find, download and install updates from PowerShell, with signature checks.

3.2.1

3.2.1What it can do

Lenovo.Client.Update covers the full update lifecycle, from discovery to installation, and maintains compatibility with other Lenovo tools such as Update Retriever and ThinkVantage Repository Manager. It leverages the same "System Update" content as Lenovo Commercial Vantage. Additionally, this solution provides:

  • Digital signature verification and enforcement. Install-LnvUpdate -VerifySignature checks packages before installing them.
  • Install history in WMI. -ExportToWMI writes each installation to WMI for compliance reporting; Get-LnvUpdateHist and Get-LnvUpdateFromWmi read it back.
  • Repositories on demand. Get-LnvUpdatesRepo builds a local repository for a machine type, for full OSD task sequence support.
  • Applicability debugging. New in 1.0.6, Debug-LnvUpdate explains, package by package, which applicability and install-detection tests a machine did or did not satisfy.
3.2.2

3.2.2Examples

# Get applicable updates
$updates = Get-LnvUpdate
$updates

# Download, then install with signature verification
$updates | Save-LnvUpdate -Path 'C:\Updates' -ShowProgress
$updates | Install-LnvUpdate -Path 'C:\Updates' -VerifySignature -Verbose

# OSD: build a local repository, then install from it and record to WMI
Get-LnvUpdatesRepo -MachineTypes 21NT -RepositoryPath 'C:\Repo'
Get-LnvUpdate -Repository 'C:\Repo' | Install-LnvUpdate -ExportToWMI

3.2.4Migrating from LSUClient

The Lenovo.Client.Update module originated as a fork of the LSUClient community module on GitHub. The core commands work identically under new names, so most scripts designed for LSUClient can migrate by simply renaming these commands:

LSUClientLenovo.Client.Update
Get-LSUpdateGet-LnvUpdate
Save-LSUpdateSave-LnvUpdate
Install-LSUpdateInstall-LnvUpdate
Expand-LSUpdateExpand-LnvUpdate
Get-LSUClientConfigurationGet-LnvUpdateConfiguration
Set-LSUClientConfigurationSet-LnvUpdateConfiguration

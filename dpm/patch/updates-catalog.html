Lenovo's third-party catalog for Configuration Manager and WSUS.

2.2.1

2.2.1How it works

The Lenovo Updates Catalog is Lenovo's Third-Party Partner Catalog. You subscribe to it under Software Library > Software Updates > Third-Party Software Update Catalogs in Configuration Manager, and its content is deployed and managed with ConfigMgr and WSUS. WSUS administrators get the approval workflow they already know.

The V3 format categorizes updates by model. Instead of every update in the catalog being published as metadata, you choose the categories you need, which cuts the data your site manages and the work clients do during scan cycles.

2.2.2

2.2.2The Catalog Agent

To decide whether a driver update is applicable, installed or not needed, the WSUS Catalog XML schema needs data that is programmatically comparable. The Lenovo Updates Catalog Agent is a lightweight service that gathers data from Win32_PNPSignedDriver class, normalizes the data, and stores it in one place: the Win32_PNPSignedDriverEx class in the Root\Lenovo\drivers WMI namespace. Each update's IsInstalled and IsInstallable rules query this custom class. This is primarily needed for hardware driver updates and not BIOS updates.

The agent is itself published in the catalog as a software update (currently LUCAgent1007). Enable the Lenovo, Lenovo Updates and LUCAgent products on your Software Update Point, synchronize, and deploy the agent to your ThinkPad, ThinkStation and ThinkCentre devices before any Lenovo updates. It runs whenever a Software Updates Scan Cycle or Deployment Evaluation Cycle starts.

Without the agent, Lenovo updates stay in the Unknown column of your compliance reports. With it, results move to Required, Installed or Not Required as devices scan, subject to your site's summarization schedule.

2.2.3

2.2.3What it cannot deliver

Because of WSUS content restrictions and some component vendor limitations, the catalog cannot carry firmware, including all dock firmware, or certain drivers that require a setup.exe or some other executable in order to determine applicability. Cover those with Commercial Vantage, Lenovo.Client.Update or Dock Manager.

WSUS is deprecated

Microsoft has deprecated WSUS. No new features will be developed, and it will be removed from a future release of Windows Server. Plan your migration to a modern patching solution.

Why automate with ThinkVantage?

For more than three decades, Lenovo has worked alongside enterprise IT organizations to understand what it takes to operate PCs at scale. The result is an Enterprise Readiness specification and checklist that helps guide Lenovo product teams as they design ThinkPad, ThinkCentre, and ThinkStation systems. This framework ensures devices are built not only to perform, but also to integrate seamlessly into tightly managed business environments where consistency, governance, security, and operational control are required. This same focus on reducing friction has gone into the development of the solutions within the ThinkVantage PowerShell Library.

Consistent, repeatable deployments Script-driven updates eliminate manual steps and configuration drift across your entire device fleet.
Full PowerShell flexibility Cmdlets provide the basic building blocks to build your custom process.
Intune integration Package BIOS configurations as Win32 apps or Remediations and deploy via Microsoft Intune with MS Graph upload. Manage Commercial Vantage policies natively in Intune.
Enterprise security built in Digital signature verification, certificate-based BIOS authentication, and Azure Key Vault integration for zero-trust deployments.
OSD and task sequence optimized Dynamically install applicable updates during bare-metal deployments without maintaining static driver packages.

Four powerful modules

Everything can be installed from PowerShell Gallery or manually downloaded from the Docs site. Install what you need and script the rest.

Lenovo.Client.Update Discover, download, and install driver, BIOS/UEFI, and firmware updates on Lenovo PCs. Complete automation control. Use in OSD, with local repository or direct from Lenovo. You control the experience. Install-Module Lenovo.Client.Update
Lenovo.BIOS.Config Read and modify BIOS settings via WMI. Export/import INI profiles with encrypted passwords. Package configurations for Microsoft Intune deployment. Install-Module Lenovo.BIOS.Config
Lenovo.Bios.Certificates Replace Supervisor passwords with X.509 certificates. Sign BIOS commands cryptographically via local key files or Azure Key Vault — no password transmitted. Install-Module Lenovo.Bios.Certificates
Lenovo.Client.Scripting Query device info, search driver and HSA packs, gather BIOS details, and track warranty status. Install-Module Lenovo.Client.Scripting

Real workflows

Provided here are a few examples of how to tackle some common scenarios.

PS Get - Save - Install 
# 1. Discover applicable updates for this machine
$updates = Get-LnvUpdate
$updates | Format-Table -Property Title, Category, ReleaseDate  # Optional - view the applicable updates found.
 
# 2. Download to a local staging directory
$updates | Save-LnvUpdate -Path "C:\Lenovo\Updates" -ShowProgress
 
# 3. Install with verbose output
$updates | Install-LnvUpdate -Path "C:\Lenovo\Updates" -Verbose

Tip: Filter for silent-only packages first — Where-Object { $_.Installer.Unattended } — before Save and Install.

PS OSD Task Sequence 
# Stage a local repo — exclude packages that force reboot (type 1)
$repo = 'C:\Lenovo_Updates'
Get-LnvUpdatesRepo -RepositoryPath $repo -RebootType '0,3,5'
 
# First pass: install applicable updates, log history to WMI
Get-LnvUpdate -Repository $repo |
    Install-LnvUpdate -Path $repo -ExportToWMI -Verbose
 
# Second pass: catches chained driver dependencies
Get-LnvUpdate -Repository $repo |
    Install-LnvUpdate -Path $repo -ExportToWMI

Run Get-LnvUpdate twice — some drivers only become applicable after a prerequisite has been installed.

PS BIOS Settings Capture & Deploy 
# Export current BIOS settings to an INI file
Export-LnvWmiSettings -ConfigFile "C:\Temp\t14gen7i-bios.ini" -NoKey
 
# Apply INI to a target device (prompts for Supervisor Password)
$svp = Read-Host -AsSecureString 'Supervisor Password'
Import-LnvWmiSettings -ConfigFile 'C:\Temp\t14gen7i-bios.ini' -Current $svp
 
# Launch the GUI (elevated terminal required)
ThinkBIOSConfigUI   # Actions → Create Intune Package → Upload
PS Azure Key Vault 
# Authenticate to Azure
Connect-AzAccount
 
# Sign a single BIOS setting change via Key Vault
$cmd = Get-LnvSignedWmiCommand -Method SetBiosSetting `
    -VaultName "CorpKeyVault" -KeyName "BiosSigningKey" `
    -SettingName "WakeOnLAN" -SettingValue "Enable"
Submit-LnvBiosChange -Command $cmd
 
# Or process an entire INI config file
Convert-LnvBiosConfigFile -ConfigFile "settings.ini" `
    -VaultName "CorpKeyVault" -KeyName "BiosSigningKey"
Submit-LnvBiosConfigFile -ConfigFile "SignedSettings.ini"

Up and running in minutes

Run in an elevated PowerShell session.

# Install all three modules from PowerShell Gallery
Install-Module 'Lenovo.Client.Update'
Install-Module 'Lenovo.BIOS.Config'
Install-Module 'Lenovo.Bios.Certificates'
 
# Install the optional GUI tools
Install-Script 'ThinkBiosConfigUI'
Install-Script 'LnvBiosCertInterface'
 
# Verify: run your first update check
Get-LnvUpdate | Format-Table -Property Title, Category, ReleaseDate

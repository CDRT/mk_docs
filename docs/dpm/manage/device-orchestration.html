3.6.5Working with Commercial Vantage

Commercial Vantage 2026 releases deepen the integration with Device Orchestration. They send clearer error messages and stage-by-stage logging back to the console, support driver rollback controlled from Device Orchestration, and hold update prompts while the user is in a full-screen application.

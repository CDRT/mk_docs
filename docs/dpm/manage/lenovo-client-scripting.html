3.4.1

3.4.1What it covers

A general-purpose toolkit for the questions admins ask every day: what is this device, is it under warranty, which BIOS is it on, which CVEs does a BIOS update address, and where is its driver pack.

  • Device identity: machine type, serial number, model name.
  • BIOS details, available BIOS versions, and the CVEs a BIOS update addresses.
  • Warranty and battery information.
  • Driver pack and HSA pack search, with checksums and download URLs.
  • Update history, applicable updates, and log analyzers for Commercial Vantage and Thin Installer.

3.4.3Examples

# CVEs addressed in the current BIOS update for a machine type
Get-LnvCVE -MachineType 21DD

# Only the latest driver pack for a machine type
Find-LnvDriverPack -MachineType 21DD -Latest

# Warranty status (written to WMI by Commercial Vantage)
Get-LnvWarranty
3.4.4

3.4.4What changed in 2.4

Version 2.4.0 (April 6, 2026) shipped alongside the ThinkVantage PowerShell Library launch. It added Invoke-LnvCVLogViewer, Invoke-LnvTILogViewer, Show-LnvUpdatesHistory and Get-LnvSystemFirmwareVersion, and Find-LnvDriverPack now returns structured objects with Model, OS, OSVersion, SHA256, MD5, DateReleased and URL properties.

Version 2.4.1 removed Get-LnvUpdate and Get-LnvUpdatesRepo, which now live in Lenovo.Client.Update.

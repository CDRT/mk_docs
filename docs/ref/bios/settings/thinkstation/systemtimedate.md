# System Time and Date

### **System Time**

Set the system time.

Use arrow keys to switch between time fields.

Possible options:

1. **Currently set date**
2. HH : MM : SS

    a. HH - Hour: 00 ~ 23

    b. MM - Minute: 00 ~ 59

    c. SS - Second: 00 ~ 59

### **System Date**

Set the system date.

Use arrow keys to switch between date fields.

Possible options:

1. **Currently set date**
2. MM/DD/YYYY:

    a. MM – Months: January to December

    b. DD – Date: 1 ~ 31

    c. YYYY – Year: 1980 ~ 2099

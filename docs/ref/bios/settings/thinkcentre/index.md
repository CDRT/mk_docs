# ThinkCentre BIOS Settings

This section describes the BIOS settings available on Lenovo ThinkCentre systems. Not all models implement all settings, so it is recommended to review a sample system to identify which settings are available.

Settings are listed in the same order as the BIOS menus and the navigation menu on the left.

## Main

- [Main](main.md): language and setup mode.
- [System Summary](system_summary.md): system information and installed components.
- [System Time and Date](system_time_and_date.md): the system time and date.

## Devices

- [Devices](devices.md): Bluetooth and card reader.
- [Serial Port Setup](serial_port_setup.md): serial port addresses and interrupts.
- [Parallel Port Setup](parallel_port_setup.md): parallel port address, mode and IRQ.
- [USB Setup](usb_setup.md): USB port access, BIOS support and enumeration delay.
- [Storage Setup](storage_setup.md): SATA controller, drive and M.2 options.
- [ATA Drive Setup](ata_drive_setup.md): SATA controller, drive options and hard disk pre-delay.
- [Video Setup](video_setup.md): active video device, memory sizes and DisplayPorts.
- [Audio Setup](audio_setup.md): onboard audio controller, internal speaker and microphone.
- [Network Setup](network_setup.md): onboard Ethernet and wireless LAN options.
- [PCI Express Configuration](pci_express_configuration.md): ASPM support and PCIe slot speeds.
- [Intel(R) Thunderbolt](intel_r_thunderbolt.md): Thunderbolt technology, security level and wake options.

## Advanced

- [Advanced](advanced.md): memory encryption, Thunderbolt, Dust Shield Alert and other advanced options.
- [CPU Setup](cpu_setup.md): EIST, Speed Shift, Hyper-Threading, core count and virtualization.
- [Intel(R) Manageability](intel_r_manageability.md): Intel Manageability control, reset and MEBx.
- [DASH Configuration](dash_configuration.md): DASH support and console redirection.

## Power

- [Power](power.md): behavior after power loss, Enhanced Power Saving Mode and Smart Power On.
- [Intelligent Cooling](intelligent_cooling.md): performance mode and fail-safe protection.
- [Automatic Power On](automatic_power_on.md): Wake on LAN, serial port ring and alarm wake.

## Security

- [Security](security.md): supervisor, power-on and system management passwords.
- [System Management Password Access Control](system_management_password_access_control.md): give the system management password supervisor-level control.
- [Hard Disk Password](hard_disk_password.md): per-drive passwords and boot requirements.
- [Password Policies](password_policies.md): minimum length, strong passwords and when a BIOS password is required.
- [TCG Feature Setup](tcg_feature_setup.md): TCG security device state and Security Chip 2.0.
- [System Event Log](system_event_log.md): view or clear the system event log.
- [Secure Boot](secure_boot.md): system mode, Secure Boot, factory keys and audit mode.
- [Certificate Based BIOS Authentication](certificate_based_bios_authentication.md): use a digital certificate instead of a supervisor password.
- [Computrace](computrace.md): Absolute Persistence version and module (display only).

## Startup

- [Startup](startup.md): first boot device, USB boot support and Fast Boot.
- [Boot Priority Order](boot_priority_order.md): the order the system uses to find a boot device.

## Exit

- [Exit](exit.md): save or discard changes, and load defaults.

# ThinkPad BIOS Settings

This section describes the BIOS settings available on Lenovo ThinkPad systems. Not all models implement all settings, so it is recommended to review a sample system to identify which settings are available.

Settings are listed in the same order as the BIOS menus and the navigation menu on the left.

## Main

- [Main](main.md): view-only system information.

## Config

- [Config](config.md): the setup interface type, keyboard-only text or graphical.
- [Network](network.md): Wake On LAN, Wi-Fi configuration and custom URL support.
- [USB](usb.md): Always on USB and charging in battery mode.
- [Keyboard & Mouse](keyboardmouse.md): TrackPoint, trackpad and function key options.
- [Display](display.md): boot display device, graphics device and ePrivacy Lock.
- [Storage](storage.md): storage controller operating mode.
- [Power](power.md): power management and automatic power on.
- [Beep & Alarm](beepalarm.md): beep behavior when the system waits for a password.
- [CPU](cpu.md): processor options such as Efficient-cores support.
- [AIM-T](aimt.md): AMD Integrated Manageability Technology on AMD PRO platforms.
- [Thunderbolt(TM) 4](thunderbolttm4.md): PCIe tunneling and related options.
- [Intel(R) AMT](intelramt.md): Intel Active Management Technology.
- [HDMI Configuration](hdmi.md): HDMI output mode.

## Date/Time

- [Date/Time](datetime.md): the system date and time.

## Security

- [Password](password.md): supervisor, system management, power-on and drive passwords, and related options.
- [Fingerprint](fingerprint.md): fingerprint authentication before the operating system starts.
- [Security Chip](securitychip.md): security chip type, state and reporting options.
- [UEFI BIOS Update Option](uefibiosupdate.md): whether the BIOS can be updated without the supervisor password.
- [Memory Protection](memoryprotection.md): Data Execution Prevention.
- [Intel(R) SGX](intelsgx.md): Intel Software Guard Extensions.
- [Virtualization](virtualization.md): Kernel DMA Protection, Intel VT or AMD-V, and VT-d.
- [I/O Port Access](ioportaccess.md): enable or disable built-in devices and ports.
- [Internal Device Access](internaldeviceaccess.md): tamper detection.
- [DASH Configuration](dash.md): out-of-band remote management on AMD PRO platforms.
- [Absolute Persistence(R) Module](abspersistencemodule.md): the optional Absolute Software monitoring service.
- [Secure Boot](secureboot.md): prevent unauthorized operating systems from running at boot time.
- [Device Guard](deviceguard.md): Microsoft Device Guard.
- [ThinkShield Secure Wipe](thinkshieldsecurewipe.md): secure wipe from the F12 App Menu.
- [ThinkShield Passwordless Power-On](thinkshieldpasswordless.md): sign in at power-on with a FIDO2 USB device.
- [ThinkShield Wipe System Data](thinkshieldwipedata.md): permanently delete data from the system.
- [Intelligent Security](intelligentsecurity.md): lock and unlock the computer by detecting your presence.
- [Reset System to Factory Defaults](resetsystemtofactorydefaults.md): reset the system, introduced on 2023 products.
- [Certificate-based BIOS Authentication](certbasedbiosauth.md): use a digital signing certificate instead of a supervisor password.

## Startup

- [Startup](startup.md): boot mode, boot order, network boot and related options.

## Restart

- [Restart](restart.md): exit Setup, save or discard changes, and load defaults.
